Quick Start

From download to running stack in a few steps.

Aspire Boot is designed to get you to a working local environment fast, with frontend, API, worker, and infrastructure launched under the Aspire experience.

1. Install basics

Use .NET 10 SDK, Docker or Podman, and Node.js for the Angular app.

2. Trust local HTTPS

Generate dev certificates and local certs once, then let the stack run with friendly local domains.

3. Run AppHost

Launch the AppHost and get dashboard, API docs, frontend, broker, and cache tooling together.
